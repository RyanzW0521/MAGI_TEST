## 当前基线边界

- Agent 仍是 `FakeAgent`，不代表真实外部 Agent 的不可信输出行为。
- 存储和运行时仍是 v0.1 的内存实现；本分支尚未引入 Paseo 或真实 Provider。
- 治理职责仍由 MAGI Runtime 负责：状态机、Policy、HumanGate、Audit、Artifact provenance 和独立 Evidence 验证。
- v0.1 不启用真实 shell/network；因此本次基线复核没有执行真实外部命令或网络调用。

## v0.2-P-r1 待验证缺口

P0-1 必须先用真实可用的 Paseo SDK/daemon 证据探测 provider、生命周期、session、streaming、取消/关闭能力，以及 orchestration 是否存在 ACP/MCP/native 绕行路径。P0-1 完成前不冻结 Backend 接口。

后续还需验证：真实 tool-call 输出及 Normalizer、三贤人垂直切片、Workspace/Trust Boundary、ControlledExecutor 最小约束、PatchSnapshot/TOCTOU 和独立验证。

## 残余风险声明

即使后续 P0 通过，交付文档仍须明确：P0 ControlledExecutor 不是完整 sandbox；验证阶段仍可能执行不可信测试代码；Paseo daemon 被攻破时不提供抵抗能力。git worktree、专用 daemon 和 observer-only 只能降低风险，不能宣称 OS/kernel 隔离或完美的 prompt-injection、供应链、多租户和 RBAC 防护。
